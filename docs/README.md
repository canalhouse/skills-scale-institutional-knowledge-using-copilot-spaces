# OctoAcme Project Management Documentation

Welcome to the OctoAcme Project Management Docs. This README contains an overview of the project management processes used by OctoAcme, along with links to all related process documents in this repository.

## Summary: OctoAcme Project Management Processes

OctoAcme's project management is built on customer-first principles, iterative delivery, clear ownership, and data-informed decisions. Key activities include:

- Clear roles: Project Manager, Product Manager, Developers, QA, Stakeholders
- Documented project lifecycle: Initiation, Planning, Execution, Release, Retrospective/Close
- Focused on transparency, psychological safety, and regular communication across all stages
- Key artifacts: Project Charter/One-pager, Backlog, Roadmap, Risk Register, Acceptance Criteria, and more
- Use project boards, regular cadence meetings (standups, reviews, syncs), and lightweight documentation for consistency

Refer to [OctoAcme Project Management Overview](./octoacme-project-management-overview.md) for a detailed methodology, principles, roles, and lifecycle.
